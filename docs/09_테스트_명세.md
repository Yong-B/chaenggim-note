# 09. 테스트 명세

## 1. 백엔드 공통

- JUnit 5 + AssertJ. 테스트마다 한국어 `@DisplayName`.
- 고정 Clock: `2026-11-09T09:00 Asia/Seoul`(월요일). 테스트용 `@TestConfiguration`에서 `@Primary Clock` 등록.
- 아래 표의 테스트는 **모두** 작성한다. 추가는 자유.
