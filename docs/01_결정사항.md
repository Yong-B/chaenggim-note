# 01. 결정사항

> 1·2·3절은 **사용자가 확정한 결정**이다. 4절은 확정된 결정을 문서로 옮기면서 생긴 **세부 규칙(추천 적용)**으로, 사용자가 바꿀 수 있다.
> 결정을 바꾸려면 이 파일을 먼저 고치고, 영향받는 문서를 함께 수정한다. 구현하는 Claude는 이 파일에 없는 결정을 임의로 내리지 않는다.

## 1. 기능 결정 (확정)

| # | 항목 | 결정 |
| --- | --- | --- |
| D1 | 질문과 약속 | **분리** (Question / Commitment 별도) |
| D2 | 질문 상태 | **4단계**: 미답변 / 확인 중 / 답변 준비됨 / 전달 완료 |
| D3 | 답변 출처 | **필수** (출처 종류 3종 중 선택 필수, 출처 상세는 선택) |
| D4 | 기록 단위 | **의료진 중심**. 병원은 의료진의 정보 |
| D5 | 홈 구성 | **방문 예정 기반**: 기한 지난 약속 → 오늘까지인 약속 → 이번 주 방문 예정 → 질문 현황 |
| D6 | 제품 태그 | **P1(후순위)**. DB 칸은 처음부터 둔다 |
| D7 | DB | **H2(기본) + 설정만 바꿔 MySQL 전환 가능** |
| D8 | 화면 기준 | **반응형** (휴대폰·PC 모두) |
| D8-1 | PC 구성 | **휴대폰 하단 탭 → PC 왼쪽 메뉴**, 본문 넓힘, 홈 카드 2열 |
| D9 | 앱 이름 | **챙김노트** (`chaenggim-note`) |
| D10 | 방문 기록 입력 | **"+ 추가" 버튼**으로 질문·약속 각각 **최대 10개** |
| D11 | 전달 완료 질문 | **완전 잠금**: 내용·답변 수정, 삭제, 상태 되돌리기 모두 불가 |
| D12 | 약속 기한 | **필수**. 완료·완료 취소 모두 가능 |
| D13 | 다음 방문 예정일 | **방문 기록 화면에서도 입력**. 비우면 기존 값 유지. 의료진 수정 화면에서도 변경 가능 |
| D14 | 의료진 삭제 | **숨김 처리(기록 보존)**. 되살리기 없음 |
| D15 | 방문 기록 수정 | **날짜·메모만**. 질문·약속은 각자 화면에서 수정 |
| D16 | 방문 기록 삭제 | **연결된 질문·약속 함께 삭제. 전달 완료 질문이 있으면 삭제 불가** |

## 4. 세부 규칙 (추천 적용 · 변경 가능)

### 4.1 확정 결정에서 파생된 규칙

| # | 규칙 | 근거 |
| --- | --- | --- |
| R1 | 질문·약속은 반드시 하나의 방문에 속한다 (`visit_id NOT NULL`). 질문의 "받은 날"은 별도 저장하지 않고 방문 날짜를 쓴다 | 질문·약속은 방문 기록 작성 시에만 생성(D10, D15) |
| R2 | 방문 날짜를 고치면 그 방문의 질문 "받은 날"도 함께 바뀐다. 전달 완료 질문이 있어도 방문 날짜 수정은 허용 | D11은 질문의 내용·답변·상태 잠금. 방문 날짜는 방문의 사실 정정 |
| R3 | 질문 내용 수정은 미답변·확인 중·답변 준비됨에서 가능 | D11 |
| R4 | 약속 수정(내용·기한)은 미완료일 때만. 완료된 약속은 완료 취소 후 수정 | 완료 기록 보존 |
| R5 | 약속 기한을 **바꿀 때** 오늘 이전 날짜 불가. 기한을 그대로 두고 내용만 고치면 지난 기한이어도 허용 | D12 |
| R6 | 약속 삭제는 완료 여부와 관계없이 가능 | 약속에는 잠금 규칙이 없음 |
| R7 | 숨김 처리된 의료진과 그 방문·질문·약속은 홈, 목록, 검색, 질문함, 개수 어디에도 나오지 않고, 상세 조회 시 404 | D14 |
| R8 | 방문 기록 작성 시 질문·약속이 0개여도 저장 가능 | 방문 메모만 남기는 경우 |

### 4.2 기술 세부

| # | 항목 | 값 |
| --- | --- | --- |
| V1 | Java / Spring Boot | Java 17 / Spring Boot 3.3.5 / Gradle Groovy |
| V2 | Node / 패키지 관리 | Node 20 LTS / npm |
| V3 | React / Vite | React 18 / Vite 5 (`npm create vite@5` 의 `react-ts` 템플릿) |
| V4 | 개발 서버 연결 | Vite proxy로 `/api` → `http://localhost:8080`. 백엔드 CORS 설정 없음 |
| V5 | 스타일 | 일반 CSS 파일 1개 `frontend/src/styles/app.css`. CSS 프레임워크·UI 컴포넌트 라이브러리 없음 |
| V6 | 폼 | React 상태(useState)로 직접 관리. 폼 라이브러리 없음 |
| V7 | 확인창 | 삭제·초기화 확인은 브라우저 기본 `window.confirm` |
| V8 | 시간대 | 백엔드 `Clock` = Asia/Seoul. 프론트의 오늘 날짜 기본값은 브라우저 로컬 날짜, 최종 검증은 백엔드 |
