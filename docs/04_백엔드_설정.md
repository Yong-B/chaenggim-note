## 3. 설정 파일

### 3.1 `src/main/resources/application.yml` (기본 = H2)

```yaml
spring:
  application:
    name: chaenggim-note
  datasource:
    url: jdbc:h2:file:./data/chaenggim;MODE=MySQL;DATABASE_TO_LOWER=TRUE;AUTO_SERVER=TRUE
    username: sa
    password:
    driver-class-name: org.h2.Driver
  sql:
    init:
      mode: always
      schema-locations: classpath:db/schema-h2.sql
  jpa:
    hibernate:
      ddl-auto: validate
    open-in-view: false
    properties:
      hibernate:
        format_sql: true
        default_batch_fetch_size: 100
  h2:
    console:
      enabled: true
      path: /h2-console

server:
  port: 8080

chaenggim:
  zone: Asia/Seoul
  seed-on-empty: true

logging:
  level:
    org.hibernate.SQL: debug
```

### 3.2 `src/main/resources/application-mysql.yml` (MySQL 전환용)

실행: `./gradlew bootRun --args='--spring.profiles.active=mysql'`

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/chaenggim?serverTimezone=Asia/Seoul&characterEncoding=UTF-8
    username: ${DB_USERNAME:chaenggim}
    password: ${DB_PASSWORD:chaenggim}
    driver-class-name: com.mysql.cj.jdbc.Driver
  sql:
    init:
      schema-locations: classpath:db/schema-mysql.sql
  h2:
    console:
      enabled: false
```

DB 생성(사용자가 직접): `CREATE DATABASE chaenggim DEFAULT CHARACTER SET utf8mb4;`

## 5. 코딩 규칙

- 컨트롤러: 요청 검증(`@Valid`) → 서비스 호출 → 응답 DTO 반환만.
- 서비스: 클래스에 `@Transactional(readOnly = true)`, 쓰기 메서드에만 `@Transactional`. 엔티티가 아닌 응답 DTO를 반환한다(트랜잭션 안에서 변환, open-in-view=false).
- 숨김 의료진 처리(R7)는 리포지토리 쿼리 조건으로 한다. 서비스에서 `findById` 후 `isDeleted()`면 `NotFoundException`.
  - 질문·약속·방문을 id로 찾을 때도 그 의료진이 숨김이면 `NotFoundException`.
- 조회는 Spring Data 메서드 이름 또는 `@Query`(JPQL). 네이티브 쿼리 금지. 목록 응답에 의료진 이름이 필요하면 fetch join.
- 날짜·시각: `LocalDate.now(clock)`, `LocalDateTime.now(clock)`.
- Lombok: `@Getter`, `@RequiredArgsConstructor`, `@NoArgsConstructor(access = PROTECTED)`만. `@Setter`, `@Data` 금지.
- JSON 날짜 형식: Spring Boot 기본(Jackson JavaTimeModule) 그대로. `LocalDate` → `"2026-11-09"`, `LocalDateTime` → `"2026-11-09T09:00:00"`(초 이하 소수점이 붙을 수 있음). 별도 포맷 설정을 추가하지 않는다.
- CORS 설정을 추가하지 않는다(개발 시 Vite proxy 사용).
