## 3. API·쿼리 규칙

### 3.1 client.ts

```ts
export type FieldError = { field: string; message: string }
type ApiResponse<T> = {
  success: boolean
  data: T
  error: { code: string; message: string; fieldErrors: FieldError[] } | null
}
export class ApiError extends Error {
  constructor(public status: number, public code: string, message: string, public fieldErrors: FieldError[]) {
    super(message)
  }
}

export async function request<T>(path: string, init?: RequestInit): Promise<T> {
  const res = await fetch(`/api${path}`, {
    headers: { 'Content-Type': 'application/json' },
    ...init,
  })
  // 백엔드는 모든 응답을 { success, data, error }로 감싼다 (05 API 명세 1절)
  const body = (await res.json().catch(() => null)) as ApiResponse<T> | null
  if (!res.ok || !body?.success) {
    throw new ApiError(
      res.status,
      body?.error?.code ?? 'UNKNOWN',
      body?.error?.message ?? '일시적인 오류가 발생했습니다. 잠시 후 다시 시도해 주세요.',
      body?.error?.fieldErrors ?? [],
    )
  }
  return body.data
}
```

### 3.2 types.ts

`05_API_명세.md`의 객체를 그대로 타입으로 옮긴다. enum은 문자열 유니온:

```ts
export type QuestionStatus = 'UNANSWERED' | 'CHECKING' | 'READY' | 'DELIVERED'
export type SourceType = 'LABEL' | 'CLINICAL' | 'MEDICAL_TEAM'
```

날짜·시각은 `string` 그대로 둔다(Date 객체로 바꾸지 않음).

### 3.3 쿼리 키 (`queries/keys.ts`)

```ts
export const keys = {
  home: ['home'] as const,
  doctors: (q: string) => ['doctors', q] as const,
  doctor: (id: number) => ['doctor', id] as const,
  visit: (id: number) => ['visit', id] as const,

  question: (id: number) => ['question', id] as const,
```

- 무효화 규칙은 `05_API_명세.md` 9절. 접두사 무효화(`{ queryKey: ['doctors'] }`)를 쓴다.
- QueryClient 기본값: `staleTime: 0`, `retry`: 404면 재시도 안 함, 그 외 1회. `refetchOnWindowFocus: true`.
- mutation 성공 후 이동이 있으면 **무효화 → 이동 → 토스트** 순서.

## 4. 공통 유틸

### 4.1 lib/date.ts

```ts
const WEEK = ['일', '월', '화', '수', '목', '금', '토']
// "2026-11-09" → "2026.11.09 (월)"
export function formatDate(d: string): string
// "2026-11-09T16:00:00(.sss)" → "2026.11.09 16:00"
export function formatDateTime(dt: string): string
// 브라우저 로컬 날짜 "YYYY-MM-DD"
export function todayString(): string
```

- `new Date("2026-11-09")`는 UTC로 해석되므로 쓰지 않는다. 문자열을 `split`해 `new Date(y, m - 1, d)`로 만든다.

### 4.2 lib/labels.ts

```ts
export const statusLabel: Record<QuestionStatus, string> = {
  UNANSWERED: '미답변', CHECKING: '확인 중', READY: '답변 준비됨', DELIVERED: '전달 완료',

  UNANSWERED: 'danger', CHECKING: 'warn', READY: 'ok', DELIVERED: 'muted',

export const productLabel: Record<ProductTag, string> = {   // P1
  ROSUZET: '로수젯', AMOSARTAN: '아모잘탄', AMOPREL: '아모프렐', EFE: '에페', ROLONTIS: '롤론티스',

```

약속 배지: overdue → `기한 지남`/danger, dueToday → `오늘까지`/warn. 의료진 pastDue → `예정일 지남`/muted.

### 4.3 폼 상태

- 각 폼은 `useState`로 값 객체 하나 + `errors: Record<string, string>` + `formError: string | null`.
- 400 응답: `fieldErrors`를 `Record`로 바꿔 `errors`에. 매칭되는 입력칸이 없는 에러는 `formError` 목록으로.
- 입력값이 바뀌면 그 필드의 에러만 지운다.
- 날짜 입력은 `<input type="date">`, 빈 값은 `null`로 전송.
- 선택 입력의 빈 문자열은 `null`로 전송.

### 4.4 Field 컴포넌트

```tsx
<Field label="이름" required error={errors.name} htmlFor="name" hint={...}>
  <input id="name" ... aria-invalid={!!errors.name} aria-describedby={errors.name ? 'name-error' : undefined} />
</Field>
```

- 라벨은 `<label htmlFor>`로 연결. 필수는 `*`(`aria-hidden`), 입력에는 `required` 속성.
- 에러 문구 요소 id는 `{htmlFor}-error`.

### 4.5 방문 기록 작성의 반복 행

- 상태: `questions: { key: string; content: string }[]`, `commitments: { key: string; content: string; dueDate: string }[]`. `key`는 `crypto.randomUUID()` (React key용, 전송 안 함).
- 전송 직전 빈 행을 제거하면서 **보낸 인덱스 → 화면 행 key** 매핑 배열을 만든다.
- 서버 에러 `questions[1].content`는 매핑으로 화면 행을 찾아 그 행 아래에 표시.
- 칸이 1개뿐일 때는 `삭제` 버튼을 숨긴다.

### 4.6 토스트

- `ToastProvider`(Context)를 Layout 바깥에 둔다. `useToast().show(message, tone)`; tone은 `'ok' | 'danger'`.
- 3초 후 자동으로 사라짐. `role="status"`(ok), `role="alert"`(danger).
- 페이지 이동 후에도 보이도록 Provider는 라우터 레이아웃 최상단.

### 4.7 확인창

`window.confirm(문구)` — 문구는 `06_화면_명세.md` 그대로.

## 6. 디자인 스킬 절차

### 6.1 설치 확인 (T7 시작 전)

설치 위치는 사용자 스킬 폴더 `~/.claude/skills/{이름}` (2026-11-09 설치). `npx skills add`는 실행 권한이 막혀 있어, GitHub 저장소의 `skills/{이름}` 폴더를 그대로 복사해 설치했다.

| 스킬 | 저장소 | 설치한 커밋 | 용도 |
| --- | --- | --- | --- |
| Hallmark | `nutlope/hallmark` (MIT) | `407fa68` | T7 디자인 결정, T8~T12 `/hallmark audit` |
| unslop | `heydamir/unslop` (CC-BY-4.0) — **UI용**(글쓰기용 unslop 아님) | `97daa3e` | T13 화면 정리 |

다시 설치할 때(같은 방식):

```bash
gh api repos/nutlope/hallmark/tarball/HEAD > hallmark.tgz   # 압축을 풀어 skills/hallmark → ~/.claude/skills/hallmark
gh api repos/heydamir/unslop/tarball/HEAD > unslop.tgz      # 압축을 풀어 skills/unslop → ~/.claude/skills/unslop
```

- 두 스킬의 `scripts/*.mjs`(Hallmark의 `theme.mjs`·`sloplint.mjs` 등)는 실행하지 않는다. Hallmark는 Node 없는 수동 경로(`references/themes/index.json`에서 직접 고르기, stamp `deal: manual`)로 쓰고, sloplint 대신 `references/gates.md`를 직접 대조한다.

스킬이 보이지 않으면 화면 작업을 시작하지 말고 사용자에게 알린다.
