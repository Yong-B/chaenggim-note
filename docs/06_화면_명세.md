# 06. 화면 명세

- 이 문서는 화면에 **무엇이** 있는지(구성·문구·동작)를 정한다. 시각 스타일은 `07_프론트_구현가이드.md`(Hallmark)를 따른다.
- 따옴표 안 문구는 **글자 그대로** 쓴다.
- 날짜 표시: `2026.11.09 (월)`, 시각 표시: `2026.11.09 16:00` (`07_프론트_구현가이드.md` 4절 `formatDate`, `formatDateTime`).
- 색 이름은 의미를 뜻한다: 위험(`danger`), 경고(`warn`), 완료(`ok`), 중립(`muted`). 실제 색은 Hallmark 디자인 결정 기록을 따른다.

## 0. 공통

### 0.1 라우트

| 경로 | 화면 | 메뉴 활성 |
| --- | --- | --- |
| `/` | 홈 | 홈 |
| `/doctors` | 의료진 목록 (`?q=` 검색) | 의료진 |
| `/doctors/new` | 의료진 등록 | 의료진 |
| `/doctors/:id` | 의료진 상세 | 의료진 |
| `/doctors/:id/edit` | 의료진 정보 수정 | 의료진 |
| `/doctors/:id/visits/new` | 방문 기록 작성 | 의료진 |
| `/visits/:id/edit` | 방문 기록 수정 | 의료진 |
| `/questions` | 질문함 (`?status=` 탭, `?product=` 제품 필터) | 질문함 |
| `/questions/:id` | 질문 상세 | 질문함 |
| `/commitments/:id/edit` | 약속 수정 | 의료진 |
| `*` | 찾을 수 없음 | 없음 |

### 0.2 레이아웃 (D8, D8-1)

| | 휴대폰 (< 768px) | PC (≥ 768px) |
| --- | --- | --- |
| 메뉴 | 화면 하단 고정 탭 3개 | 왼쪽 고정 메뉴 (위에 앱 이름 `챙김노트`, 아래 메뉴 3개) |
| 상단 | 앱 이름 `챙김노트` + 화면 제목 | 화면 제목만 (앱 이름은 왼쪽 메뉴에) |
| 본문 폭 | 화면 폭 전체 (좌우 여백) | 최대 960px |
| 홈 카드 | 1열 | 2열 (아래 1절에 배치 지정) |
| 그 외 화면 | 1열 | 1열, 폼 화면은 최대 640px |

- 메뉴 3개: `홈`(/), `의료진`(/doctors), `질문함`(/questions)
- 페이지 제목(`document.title`): `{화면 제목} · 챙김노트`
- 알림 메시지(토스트): 변경 성공 시 화면 위쪽에 3초간 표시 후 사라짐. 문구는 각 화면 절에 적힌 것. 409 에러는 같은 방식으로 에러 메시지를 표시(위험 색).

### 0.3 로딩·에러 상태 (모든 데이터 화면 공통)

| 상태 | 표시 |
| --- | --- |
| 첫 로딩 | 본문 자리에 `불러오는 중…` |
| 404 | `요청한 정보를 찾을 수 없습니다.` + 링크 `홈으로` |
| 네트워크·500 | `데이터를 불러오지 못했습니다.` + 버튼 `다시 시도` (쿼리 refetch) |
| 저장 중 | 저장 버튼 비활성 + 버튼 글자 `저장 중…` |

### 0.4 폼 공통

- 필수 입력 라벨 뒤에 `*`.
- 서버 400 응답의 `fieldErrors`를 해당 입력칸 바로 아래에 표시. 입력칸과 매칭되지 않는 에러는 폼 맨 위에 모아서 표시.
- 저장 성공 시 지정된 화면으로 이동 + 토스트.
- `취소` 링크는 이전 화면(각 절에 지정)으로 이동, 입력 내용은 버린다(확인창 없음).

## 1. 홈 `/` — 화면 제목 "오늘 챙길 것"

| 순서 | 영역 | PC 배치 |
| --- | --- | --- |
| ① | 날짜 줄 `오늘 2026.11.09 (월)` | 전체 폭 |
| ② | 기한 지난 약속 | 왼쪽 열 |
| ③ | 오늘까지인 약속 | 왼쪽 열 (②아래) |
| ④ | 이번 주 방문 예정 | 오른쪽 열 |
| ⑤ | 질문 현황 | 전체 폭 |
| ⑥ | 초기화 버튼 | 전체 폭, 맨 아래 |

**② 기한 지난 약속** — 섹션 제목 `기한 지난 약속`
- 행: 배지 `기한 지남`(위험), 약속 내용, `{의료진 이름} · {병원}`, `기한 2026.11.07 (토)`, 버튼 `완료`
- 행(버튼 제외) 클릭 → 의료진 상세
- `완료` → POST complete → 토스트 `약속을 완료했습니다.`, 목록에서 사라짐
- 비었을 때: `기한 지난 약속이 없습니다.`

**③ 오늘까지인 약속** — 섹션 제목 `오늘까지인 약속`
- ②와 같고 배지만 `오늘까지`(경고). 비었으면 **섹션을 숨긴다**.

**④ 이번 주 방문 예정** — 섹션 제목 `이번 주 방문 예정`
- 행: 의료진 이름, `{병원} · {진료과}`, `방문 예정 2026.11.10 (화)`, pastDue면 배지 `예정일 지남`(중립)
- 숫자 칩 2개: `전달할 답변 N`, `남은 약속 N` (0이면 흐리게)
- 행 클릭 → 의료진 상세
- 비었을 때: `이번 주 방문 예정인 의료진이 없습니다.`

**⑤ 질문 현황** — 섹션 제목 `질문 현황`
- 칸 3개 가로 배치: `미답변` N, `확인 중` N, `답변 준비됨` N. 각 칸 클릭 → `/questions?status=...`

**⑥** 작은 보조 버튼 `가상 데이터로 초기화`
- 클릭 → `window.confirm('모든 데이터를 지우고 가상 데이터로 다시 채웁니다. 계속할까요?')` → POST reset → 토스트 `가상 데이터로 초기화했습니다.`

## 2. 의료진 목록 `/doctors` — 화면 제목 "의료진"

- 검색: 입력칸 placeholder `이름 또는 병원으로 검색`, 버튼 `검색`. 제출 시 URL `?q=`를 바꾼다(뒤로 가기로 이전 검색 복귀 가능).
- 버튼 `+ 의료진 등록` → `/doctors/new`
- 행: 이름, `{병원} · {진료과}`, nextVisitDate 있으면 `방문 예정 2026.11.10 (화)`. 행 클릭 → 상세
- 비었을 때(검색어 없음): `등록된 의료진이 없습니다.`
- 비었을 때(검색어 있음): `'{q}'에 해당하는 의료진이 없습니다.`

## 3. 의료진 등록·수정 `/doctors/new`, `/doctors/:id/edit`

- 화면 제목: `의료진 등록` / `의료진 정보 수정`
- 입력칸: `이름`* · `병원`* · `진료과`* · `메모`(여러 줄, placeholder `예: 오전 진료 후 방문 선호`) · `다음 방문 예정일`(날짜)
- 수정 화면은 기존 값을 채운다. 다음 방문 예정일을 비우고 저장하면 예정일이 지워진다.
- 버튼 `저장` / 링크 `취소`(등록 → `/doctors`, 수정 → `/doctors/:id`)
- 성공: 등록 → 상세로 이동 + `의료진을 등록했습니다.` / 수정 → 상세로 이동 + `의료진 정보를 수정했습니다.`

## 4. 의료진 상세 `/doctors/:id` — 화면 제목 = 의료진 이름

**① 기본 정보**: `{병원} · {진료과}`, 메모(있을 때), `다음 방문 예정 2026.11.10 (화)` 또는 `다음 방문 예정일 없음`. 링크 `정보 수정`, 텍스트 버튼 `의료진 삭제`(위험)
- `의료진 삭제` → `window.confirm('이 의료진을 목록에서 삭제할까요? 기록은 보관되지만 다시 볼 수 없습니다.')` → DELETE → `/doctors`로 이동 + 토스트 `의료진을 삭제했습니다.`

**② 큰 버튼** `+ 방문 기록` → `/doctors/:id/visits/new`

**③ 방문 전 준비** — 섹션 제목 `방문 전 준비` (강조 영역)
- 소제목 `전달할 답변`: 제품 태그(있을 때, P1), 질문 내용(굵게), 답변, `출처: 임상자료 · RACING 연구 요약`(상세 없으면 `출처: 임상자료`), 링크 `상세`. 비었을 때 `전달할 답변이 없습니다.`
- 소제목 `확인이 필요한 질문`: 상태 배지(`미답변` 위험 / `확인 중` 경고), 제품 태그(있을 때), 내용, `받은 날 2026.11.02 (월)`, 링크 `상세`. 비었을 때 `확인이 필요한 질문이 없습니다.`
- 소제목 `남은 약속`: 배지(`기한 지남` 위험 / `오늘까지` 경고 / 그 외 없음), 내용, `기한 …`, 버튼 `완료`, 링크 `수정`. 비었을 때 `남은 약속이 없습니다.`
- 소제목 `지난 방문 메모`: 최근 방문 날짜와 메모(메모 없으면 `메모 없음`). 방문 기록이 없으면 `아직 방문 기록이 없습니다.`

**④ 방문 기록** — 섹션 제목 `방문 기록`
- 행: 날짜, 메모, `질문 N · 약속 N`, 링크 `수정`, 텍스트 버튼 `삭제`(hasDelivered면 버튼 대신 작은 글씨 `전달 완료 질문이 있어 삭제 불가`)
- `삭제` → `window.confirm('이 방문 기록과 그때 기록한 질문·약속을 모두 삭제할까요?')` → DELETE → 토스트 `방문 기록을 삭제했습니다.`
- 비었을 때 `아직 방문 기록이 없습니다.`

**⑤ 전달 완료한 질문** — 제품 태그(있을 때), 내용, `전달 2026.11.03 14:00`, 링크 `상세`. 비었으면 섹션 숨김.

**⑥ 완료한 약속** — 내용(취소선), `완료 2026.10.20 18:00`, 버튼 `완료 취소`, 텍스트 버튼 `삭제`. 비었으면 섹션 숨김.
- `완료 취소` → 토스트 `완료를 취소했습니다.`
- 약속 `삭제` → `window.confirm('이 약속을 삭제할까요?')` → 토스트 `약속을 삭제했습니다.` (③ 남은 약속에는 삭제 버튼 없음. 수정 화면에 있음)

## 5. 방문 기록 작성 `/doctors/:id/visits/new` — 화면 제목 "방문 기록"

- 상단 안내: `{의료진 이름} · {병원}`
- `방문 날짜`* (날짜, 기본값 오늘)
- `방문 메모` (여러 줄, placeholder `예: 고령 환자 처방 경험 이야기 나눔`)
- 소제목 `받은 질문`
  - 처음엔 입력칸 1개. 버튼 `+ 질문 추가`로 한 칸씩 추가, 최대 10칸. 10칸이면 버튼 비활성 + 안내 `질문은 한 번에 10개까지 입력할 수 있습니다.`
  - 각 칸: 입력칸(placeholder `질문 1`, `질문 2` …) + 제품 선택(P1, 첫 옵션 `선택 안 함`, 그다음 `로수젯`·`아모잘탄`·`아모프렐`·`에페`·`롤론티스`) + 칸이 2개 이상일 때 `삭제` 버튼(그 칸 제거)
- 소제목 `약속한 것`
  - 위와 같은 방식. 각 행: 내용 입력칸(placeholder `약속 1` …) + `기한` 날짜 + `삭제`. 버튼 `+ 약속 추가`, 최대 10행, 안내 `약속은 한 번에 10개까지 입력할 수 있습니다.`
- 안내 `내용과 기한이 모두 빈 칸은 저장되지 않습니다.`
- `다음 방문 예정일` (날짜) + 안내 `비워 두면 기존 예정일을 유지합니다.`
- 버튼 `저장` / 링크 `취소`(→ 의료진 상세)
- 전송 전: 질문은 내용이 빈 칸 제거, 약속은 내용·기한이 모두 빈 행 제거. 남은 항목의 원래 칸 위치와 서버 에러 인덱스를 맞춰 표시한다(`07_프론트_구현가이드.md` 4.5절).
- 성공: 의료진 상세로 이동 + `방문 기록을 저장했습니다.`

## 6. 방문 기록 수정 `/visits/:id/edit` — 화면 제목 "방문 기록 수정"

- 상단 안내: `{의료진 이름} · {병원}`
- `방문 날짜`*, `방문 메모`만 (D15)
- 안내 `질문과 약속은 각각의 화면에서 수정할 수 있습니다.`
- 버튼 `저장` / 링크 `취소`(→ 의료진 상세)
- 성공: 의료진 상세 + `방문 기록을 수정했습니다.`

## 7. 질문함 `/questions` — 화면 제목 "질문함"

- 탭 4개: `미답변 N` · `확인 중 N` · `답변 준비됨 N` · `전달 완료 N`. 탭 클릭 시 URL `?status=` 변경.
- 제품 필터(P1): 탭 아래에 `전체` · `로수젯` · `아모잘탄` · `아모프렐` · `에페` · `롤론티스`. 클릭 시 URL `?product=` 변경(`전체`는 product 없음). 탭과 필터는 서로의 값을 유지한 채 함께 동작하고, 탭의 N도 고른 제품 기준.
- 행: 제품 태그(있을 때), 질문 내용, `{의료진 이름} · {병원}`, `받은 날 …`(전달 완료 탭은 `전달 …`). 행 클릭 → 질문 상세
- 비었을 때: `{탭 이름} 질문이 없습니다.` 예: `미답변 질문이 없습니다.`

## 8. 질문 상세 `/questions/:id` — 화면 제목 "질문 상세"

**① 질문 카드**: 상태 배지, 제품 태그(있을 때, P1), 질문 내용(크게), `{의료진 이름} · {병원}`(의료진 상세 링크), `받은 날 …`
- 전달 완료가 아니면 링크 `질문 수정` → 카드가 입력칸으로 바뀌는 인라인 편집(`저장` / `취소`). 성공 토스트 `질문을 수정했습니다.`

**② 상태별 영역**

| 상태 | 보여 줄 것 |
| --- | --- |
| 미답변 | 버튼 `확인 시작` + 안내 `학술팀 문의 등 확인을 시작하면 눌러 주세요.` + 답변 폼 |
| 확인 중 | 안내 `확인 중인 질문입니다. 확인되면 답변과 출처를 입력해 주세요.` + 답변 폼 |
| 답변 준비됨 | 답변 박스(답변, 출처, `답변 저장 2026.11.06 16:00`) + 버튼 `전달 완료` + 접힌 영역 `답변 수정`(펼치면 기존 값이 채워진 답변 폼) |
| 전달 완료 | 답변 박스 + `전달 2026.11.03 14:00` + 안내 `전달 완료된 질문은 수정할 수 없습니다.` (버튼·폼 없음) |

- `확인 시작` → 토스트 `확인 중으로 바꿨습니다.`
- `전달 완료` → `window.confirm('의료진께 답변을 전달했나요? 전달 완료 후에는 수정할 수 없습니다.')` → 토스트 `전달 완료로 바꿨습니다.`

**답변 폼**
- `답변`* (여러 줄)
- `출처`* — 라디오 3개 `허가사항` / `임상자료` / `학술팀 회신`
- `출처 상세` (placeholder `예: RACING 연구 요약 자료, 학술팀 메일 11/5`)
- 버튼 `답변 저장` → 토스트 `답변을 저장했습니다.`

**③ 맨 아래**: 전달 완료가 아니면 텍스트 버튼 `질문 삭제`(위험) → `window.confirm('이 질문을 삭제할까요?')` → 의료진 상세로 이동 + 토스트 `질문을 삭제했습니다.`

## 9. 약속 수정 `/commitments/:id/edit` — 화면 제목 "약속 수정"

- 상단 안내: `{의료진 이름} · {병원}`
- 완료된 약속이면 폼 대신 안내 `완료한 약속은 완료를 취소한 뒤 수정할 수 있습니다.` + 버튼 `완료 취소`
- 미완료: `약속 내용`*, `기한`*(날짜) + 안내 `기한을 바꿀 때는 오늘 이후 날짜만 선택할 수 있습니다.`
- 버튼 `저장` / 링크 `취소`(→ 의료진 상세) / 텍스트 버튼 `약속 삭제`(위험, `window.confirm('이 약속을 삭제할까요?')`)
- 성공: 의료진 상세 + `약속을 수정했습니다.` / 삭제 → 의료진 상세 + `약속을 삭제했습니다.`
