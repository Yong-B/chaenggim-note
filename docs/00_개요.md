# 00. 개요

## 1. 무엇을 만드는가

**챙김노트**: MR 1인이 쓰는 개인 기록 도구.

- 의료진별로 **방문 기록**, **받은 질문**, **약속한 것(약속)**을 기록한다.
- 질문은 "미답변 → 확인 중 → 답변 준비됨 → 전달 완료"로 추적하고, 답변에는 **반드시 출처**를 남긴다.
- 홈에서 **기한 지난 약속**, **오늘까지인 약속**, **이번 주 방문 예정 의료진**, **질문 현황**을 본다.
- 의료진 상세의 **방문 전 준비** 영역에서 그 의료진에게 전달할 답변과 지킬 약속을 한 번에 본다.

## 2. 왜 만드는가

- MR은 하루에 여러 의료진을 짧게 만나고, 방문마다 질문·요청이 생긴다.
- 지나가듯 받은 질문이나 "다음에 자료 가져다 드릴게요" 같은 약속은 기록하지 않으면 빠진다.
- 답을 모르는 질문은 확인 후 다시 답해야 하므로, **확인 중인 질문을 추적**할 방법이 필요하다.
- "확인한 것만 말한다"는 원칙을 지키기 위해 답변마다 근거(출처)를 남긴다.

## 3. 사용자

- MR 1인. 로그인 없음.

## 4. 범위 (v1)

| ID | 기능 | 우선순위 |
| --- | --- | --- |
| F1 | 의료진 등록·수정·삭제(숨김)·목록·검색 | P0 |
| F2 | 방문 기록 작성 (질문·약속을 같은 화면에서 각 최대 10개) | P0 |
| F3 | 방문 기록 수정(날짜·메모)·삭제 | P0 |
| F4 | 질문 내용 수정, 상태 관리(확인 시작·답변·전달), 삭제 | P0 |
| F5 | 답변 출처 필수 | P0 |
| F6 | 약속 수정·완료·완료 취소·삭제, 기한 지난 약속 강조 | P0 |
| F7 | 홈 "챙길 것" 화면 | P0 |
| F8 | 의료진 상세 "방문 전 준비" 영역 | P0 |
| F9 | 가상 시드 데이터 자동 입력 + 초기화 | P0 |
| F10 | 반응형 화면 (휴대폰·PC) | P0 |
| F11 | 질문 제품 태그(고정 5개) + 질문함 제품 필터 | P1 |

P1은 P0(T0~T14)가 모두 끝나고 사용자가 요청할 때만 구현한다(T15).

## 5. 하지 않는 것 (v1)

| 하지 않는 것 | 이유 |
| --- | --- |
| 회사 영업관리시스템(SFA/CRM) 대체 | 개인 기록 보조 도구로 한정 |
| 실적·매출·처방 데이터 | 개인 도구에서 다룰 데이터가 아님 |
| 접대비·비용 기록 | 공정경쟁규약 관련 영역. 다루지 않음 |
| 로그인·회원·권한·여러 사용자 | 1인 사용 |
| 삭제한 의료진 되살리기 | v1 범위 축소 |
| 기존 방문 기록에 질문·약속 추가 | 질문·약속은 방문 기록 작성 시에만 생성 |
| 알림(푸시, 이메일) | 범위 밖 |
| 배포, HTTPS, 운영 설정 | 로컬 실행 기준 |
| 프론트 자동 테스트 | v1은 수동 점검 체크리스트로 대신 |
| 방문 동선, 지도, 사진 | 범위 밖 |
| 실제 개인정보 저장 | 가상 데이터만 사용 |
