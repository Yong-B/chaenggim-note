# 03. DB 스키마

- DB는 기본 H2, 설정만 바꿔 MySQL로 전환(D7). 문법 차이 때문에 스키마 파일을 둘로 나눈다.
  - `src/main/resources/db/schema-h2.sql`
  - `src/main/resources/db/schema-mysql.sql`
- 애플리케이션 시작 시 매번 실행되므로 `CREATE TABLE IF NOT EXISTS`를 쓴다.
- JPA `ddl-auto: validate` — 엔티티 매핑이 DDL과 다르면 시작 시 실패한다. `@Column(name, length, nullable)`을 아래와 정확히 맞춘다.

## 1. schema-h2.sql

```sql
CREATE TABLE IF NOT EXISTS doctor (
    id               BIGINT        NOT NULL AUTO_INCREMENT,
    name             VARCHAR(30)   NOT NULL,
    hospital         VARCHAR(50)   NOT NULL,
    department       VARCHAR(30)   NOT NULL,
    memo             VARCHAR(500)  NULL,
    next_visit_date  DATE          NULL,
    deleted_at       TIMESTAMP     NULL,
    created_at       TIMESTAMP     NOT NULL,
    updated_at       TIMESTAMP     NOT NULL,
    PRIMARY KEY (id)
);

CREATE TABLE IF NOT EXISTS visit (
    id          BIGINT         NOT NULL AUTO_INCREMENT,
    doctor_id   BIGINT         NOT NULL,
    visit_date  DATE           NOT NULL,
    memo        VARCHAR(1000)  NULL,
    created_at  TIMESTAMP      NOT NULL,
    updated_at  TIMESTAMP      NOT NULL,
    PRIMARY KEY (id),
    CONSTRAINT fk_visit_doctor FOREIGN KEY (doctor_id) REFERENCES doctor (id)
);

CREATE TABLE IF NOT EXISTS question (
    id             BIGINT         NOT NULL AUTO_INCREMENT,
    doctor_id      BIGINT         NOT NULL,
    visit_id       BIGINT         NOT NULL,
    content        VARCHAR(500)   NOT NULL,
    product_tag    VARCHAR(20)    NULL,
    status         VARCHAR(20)    NOT NULL,
    answer         VARCHAR(1000)  NULL,
    source_type    VARCHAR(20)    NULL,
    source_detail  VARCHAR(200)   NULL,
    answered_at    TIMESTAMP      NULL,
    delivered_at   TIMESTAMP      NULL,
    created_at     TIMESTAMP      NOT NULL,
    updated_at     TIMESTAMP      NOT NULL,
    PRIMARY KEY (id),
    CONSTRAINT fk_question_doctor FOREIGN KEY (doctor_id) REFERENCES doctor (id),
    CONSTRAINT fk_question_visit  FOREIGN KEY (visit_id)  REFERENCES visit (id)
);

CREATE TABLE IF NOT EXISTS commitment (
    id          BIGINT        NOT NULL AUTO_INCREMENT,
    doctor_id   BIGINT        NOT NULL,
    visit_id    BIGINT        NOT NULL,
    content     VARCHAR(300)  NOT NULL,
    due_date    DATE          NOT NULL,
    done        BOOLEAN       NOT NULL DEFAULT FALSE,
    done_at     TIMESTAMP     NULL,
    created_at  TIMESTAMP     NOT NULL,
    updated_at  TIMESTAMP     NOT NULL,
    PRIMARY KEY (id),
    CONSTRAINT fk_commitment_doctor FOREIGN KEY (doctor_id) REFERENCES doctor (id),
    CONSTRAINT fk_commitment_visit  FOREIGN KEY (visit_id)  REFERENCES visit (id)
);

CREATE INDEX IF NOT EXISTS idx_doctor_deleted_next  ON doctor (deleted_at, next_visit_date);
CREATE INDEX IF NOT EXISTS idx_visit_doctor_date    ON visit (doctor_id, visit_date);
CREATE INDEX IF NOT EXISTS idx_question_doctor_stat ON question (doctor_id, status);
CREATE INDEX IF NOT EXISTS idx_question_status      ON question (status);
CREATE INDEX IF NOT EXISTS idx_question_visit       ON question (visit_id);
CREATE INDEX IF NOT EXISTS idx_commitment_done_due  ON commitment (done, due_date);
CREATE INDEX IF NOT EXISTS idx_commitment_doctor    ON commitment (doctor_id, done);
CREATE INDEX IF NOT EXISTS idx_commitment_visit     ON commitment (visit_id);
```

## 2. schema-mysql.sql

MySQL 8 기준. 인덱스는 `CREATE TABLE` 안에 둔다(MySQL은 `CREATE INDEX IF NOT EXISTS`를 지원하지 않음).
Hibernate 6의 MySQL 매핑에 맞춰 `LocalDateTime` → `DATETIME(6)`, `boolean` → `BIT(1)`.

```sql
CREATE TABLE IF NOT EXISTS doctor (
    id               BIGINT        NOT NULL AUTO_INCREMENT,
    name             VARCHAR(30)   NOT NULL,
    hospital         VARCHAR(50)   NOT NULL,
    department       VARCHAR(30)   NOT NULL,
    memo             VARCHAR(500)  NULL,
    next_visit_date  DATE          NULL,
    deleted_at       DATETIME(6)   NULL,
    created_at       DATETIME(6)   NOT NULL,
    updated_at       DATETIME(6)   NOT NULL,
    PRIMARY KEY (id),
    INDEX idx_doctor_deleted_next (deleted_at, next_visit_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE IF NOT EXISTS visit (
    id          BIGINT         NOT NULL AUTO_INCREMENT,
    doctor_id   BIGINT         NOT NULL,
    visit_date  DATE           NOT NULL,
    memo        VARCHAR(1000)  NULL,
    created_at  DATETIME(6)    NOT NULL,
    updated_at  DATETIME(6)    NOT NULL,
    PRIMARY KEY (id),
    INDEX idx_visit_doctor_date (doctor_id, visit_date),
    CONSTRAINT fk_visit_doctor FOREIGN KEY (doctor_id) REFERENCES doctor (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE IF NOT EXISTS question (
    id             BIGINT         NOT NULL AUTO_INCREMENT,
    doctor_id      BIGINT         NOT NULL,
    visit_id       BIGINT         NOT NULL,
    content        VARCHAR(500)   NOT NULL,
    product_tag    VARCHAR(20)    NULL,
    status         VARCHAR(20)    NOT NULL,
    answer         VARCHAR(1000)  NULL,
    source_type    VARCHAR(20)    NULL,
    source_detail  VARCHAR(200)   NULL,
    answered_at    DATETIME(6)    NULL,
    delivered_at   DATETIME(6)    NULL,
    created_at     DATETIME(6)    NOT NULL,
    updated_at     DATETIME(6)    NOT NULL,
    PRIMARY KEY (id),
    INDEX idx_question_doctor_stat (doctor_id, status),
    INDEX idx_question_status (status),
    INDEX idx_question_visit (visit_id),
    CONSTRAINT fk_question_doctor FOREIGN KEY (doctor_id) REFERENCES doctor (id),
    CONSTRAINT fk_question_visit  FOREIGN KEY (visit_id)  REFERENCES visit (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE IF NOT EXISTS commitment (
    id          BIGINT        NOT NULL AUTO_INCREMENT,
    doctor_id   BIGINT        NOT NULL,
    visit_id    BIGINT        NOT NULL,
    content     VARCHAR(300)  NOT NULL,
    due_date    DATE          NOT NULL,
    done        BIT(1)        NOT NULL DEFAULT b'0',
    done_at     DATETIME(6)   NULL,
    created_at  DATETIME(6)   NOT NULL,
    updated_at  DATETIME(6)   NOT NULL,
    PRIMARY KEY (id),
    INDEX idx_commitment_done_due (done, due_date),
    INDEX idx_commitment_doctor (doctor_id, done),
    INDEX idx_commitment_visit (visit_id),
    CONSTRAINT fk_commitment_doctor FOREIGN KEY (doctor_id) REFERENCES doctor (id),
    CONSTRAINT fk_commitment_visit  FOREIGN KEY (visit_id)  REFERENCES visit (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

> MySQL 경로는 자동 테스트로 검증하지 않는다(테스트는 H2). MySQL 실행 시 `ddl-auto: validate` 오류가 나면, 오류 메시지의 컬럼 타입만 이 파일에서 맞추고 **엔티티는 바꾸지 않는다**. 바꾼 내용은 이 문서에 반영한다.

## 3. 삭제 순서

| 상황 | 순서 |
| --- | --- |
| 초기화(전체 삭제) | question → commitment → visit → doctor |
| 방문 기록 삭제(D16) | 그 방문의 question → commitment → visit |
| 의료진 삭제(D14) | 실제 삭제 없음. `doctor.deleted_at`만 기록 |

## 4. 상태 컬럼 값

| 컬럼 | 값 |
| --- | --- |
| question.status | `UNANSWERED`, `CHECKING`, `READY`, `DELIVERED` |
| question.source_type | `LABEL`, `CLINICAL`, `MEDICAL_TEAM` |
| question.product_tag | `ROSUZET`, `AMOSARTAN`, `AMOPREL`, `EFE`, `ROLONTIS` |
