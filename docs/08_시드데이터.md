# 08. 시드 데이터

- 모든 이름·병원은 **가상**이다. 실제 이름으로 바꾸지 않는다.
- 날짜는 실행 시점 기준 상대값. `T = LocalDate.now(clock)`, `T-7` = 7일 전. 시각 `T-3 16:00` = `T.minusDays(3).atTime(16, 0)`.
- `SeedService.seed()`는 **엔티티 정적 팩토리와 도메인 메서드만** 사용한다(요청 검증을 거치지 않으므로 지난 기한 약속도 만들 수 있다).
- 저장 순서: 의료진 → 방문 → 질문 → 약속 (표의 순서대로).
- `SeedRunner`: 시작 시 `chaenggim.seed-on-empty=true`이고 의료진(숨김 포함) 0명이면 `seed()`.
- `SeedService.reset()`: question → commitment → visit → doctor 순서로 전부 삭제 후 `seed()`. 한 트랜잭션.
